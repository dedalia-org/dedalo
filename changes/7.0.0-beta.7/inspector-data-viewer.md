---
title: The inspector's Data box keeps its size when you select another component, and you can resize it.
type: changed
audience: user
date: 2026-10-19
---
Before, the inspector rebuilt the component information each time you selected a
component. The Data box briefly collapsed, then grew or shrank to fit that
component's value, which moved Project, Relations and Latest changes up and down.

Now the Data box has a fixed height of 10rem whatever the value. Drag its bottom-right
corner to make it taller or shorter: the height is kept across reloads. Double-click
the box to fit it to its content for a moment. The Copy button sits in the Data
header, so you can reach it without scrolling, and it also works when a value is too
large to display. An empty value now reads "Empty".
