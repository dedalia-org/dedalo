---
title: A relation table is framed, with no rules between its column titles
type: changed
audience: user
date: 2026-10-18
---
The column titles of a relation table sat in a box each, so every pair of
neighbours drew two vertical rules between them and the titles read as a grid of
sealed cells. Those boxes stopped at the header too, leaving the left rule
hanging above the rows.

The titles are labels, not fields, so the rules between them are gone. The
table's own edges carry the frame instead: one rule down each side, from the
titles to the last row, plus the line above the titles. No column moves.
