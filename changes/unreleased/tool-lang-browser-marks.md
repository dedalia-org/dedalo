---
title: The Local AI translator no longer loses, reverses or invents marks silently
type: fixed
audience: user
date: 2026-11-22
---
Before, when the in-browser translation model dropped an index mark, a time code or another mark, the mark simply vanished from the translated text. When it reversed an opening and closing mark, they were saved reversed. Both runs reported *Translation completed*. Now marks, links, superscripts and other formatting are kept out of the model's reach and put back unchanged, and long texts are translated a few sentences at a time, each list item, table cell or paragraph on its own. The formatting comes back exactly as it was — bold and italic in the same tags, spacing and indentation, empty spacer paragraphs, non-breaking spaces, comments, paragraph attributes and characters of epigraphic fonts; `*`, `_` and `` ` `` in the text (`2*3*4 g`, `` l`Hospitalet ``) are saved as written even when the model drops their escaping, and an unknown or obsolete tag inside a paragraph no longer splits it. A mark the model dropped is placed by the translator itself, and reversed pairs are put back in order; the result is saved with **Translation saved — check the marks** and a line saying what was moved. A mark that is still missing, appears twice or is not in the source, paragraphs, list items or cells that came back in a different order, formatting that came back wrongly nested, a passage the model returned empty, HTML the model wrote of its own, a part of the text the model failed on, or a model that repeated itself instead of translating stops the run: nothing is saved, the target keeps its previous text and the panel shows **Translation needs review before saving**. Text written by the model is always stored as text, never as markup, and the structure of the text (headings, lists, quotes, rules) always comes from the source: a translated paragraph that starts with a year (`1984.`), a dialogue dash or `---` is no longer turned into a list or a rule. A language with no language code the models understand (such as *no language*) is refused before the run instead of being translated as English. Stopping a run while its last part is being translated no longer saves it. The multi-language translator names every language saved with warnings in its summary. See [Translate a field](./using/tools/using_lang.md).
